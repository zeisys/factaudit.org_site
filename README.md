# factaudit.org_site

> Part of [**factaudit.org**](https://github.com/zeisys/factaudit.org) (umbrella repo: map of all the project's repos).

The FactAudit.org website: a Jekyll site published with GitHub Pages from the `docs/` folder, served at factaudit.org (see `docs/CNAME`). Formerly `factaudit.org_cms`.

## What's here

| Path | What it is |
|---|---|
| `docs/_posts/` | published fact-check posts (Markdown) |
| `docs/_json/` | the structured JSON record behind each post |
| `docs/_layouts/`, `docs/_includes/` | page templates |
| `docs/assets/`, `docs/posts/images/` | site assets and post images |
| `docs/_config.yml` | site settings |

New posts are produced from JSON by [`factaudit.org_json-to-markdown`](https://github.com/zeisys/factaudit.org_json-to-markdown).

Note: this repo is public.
